# data/app/ -- dashboard data contract

Generated by `src/export_app.py`. **Do not edit by hand** -- it is
overwritten on every run. To change a file's contents or its
description, edit `src/export_app.py`.

Data as of **2026-08-31** (last document date in the Express export).

> **The CSVs are not committed** -- they hold real revenue, and the
> database is the durable store. This contract is committed; the files
> are rebuilt locally by every pipeline run. Example values for money
> columns are shown as `1234567.89`, not the real figure.

## Reading these files

All files are UTF-8 with BOM (`utf-8-sig`), comma-separated, with an
ISO `YYYY-MM-DD` date format and `true`/`false` booleans.

> **Read code columns as text.**
> `sku_prefix`, `salesperson_code`, `customer_code` are zero-padded identifiers, not numbers.
> Any loader that infers types will read `"01"` as `1`, and every join
> against `dim_product_group.csv` will then silently return nothing.
> In pandas: `pd.read_csv(path, dtype={'sku_prefix': str})`.
> In Power BI: set the column type to Text *before* the first join.
